Verjuice

Know if it runs before you buy it.

Verjuice runs Windows games on Apple Silicon Macs. Its app, the Cellar, lays your library out as a rack of bottles, and each bottle's capsule says what that game has actually done on a Mac.

  • Gold foilVerified: played on my own Mac, with the run cited.
  • GreenRuns: launches and renders, gameplay unverified.
  • Bare corkStill corked: nobody has checked it yet.
  • Red waxSealed: refused, with the reason and the evidence.

Honest refusals beat guesses.

When a game can't run, usually because of anti-cheat, its bottle stays sealed and shows the test that proved it. You can still break the seal and play anyway, after a plain warning. Verjuice never works around anti-cheat, DRM or licensing.

Platform
macOS on Apple Silicon
App
Native SwiftUI, on a Python core
Approach
Wine, with a graphics backend picked per game and fixes it can undo
Database
Cited results from my own hardware runs
Price
Free, GPL-3.0-or-later, funded by donations
Privacy
No accounts, no telemetry
